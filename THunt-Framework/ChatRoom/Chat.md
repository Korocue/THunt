# Q43（ファイル名の2重化）
[スクリーンショット / Codexの挙動]
ファイル名が2重化して記述されるんだけど、この理由はわかる？

# A43
【ルシフォン#e】
わかる。Markdownリンクの書き方が「表示テキスト」と「リンク先」を両方 “同じパス” にしてるから、見た目として二重化してる。

いまREADMEでこうなってるはず：

[THunt-Framework/Core/Overview.md](THunt-Framework/Core/Overview.md)


[...] ← 表示される文字

(...) ← リンク先（URL/パス）

この2つが同じ文字列だから、「ファイル名が2回書かれてる」ように見えるだけ。

直し方（どれか1つ）

表示名を短くする（おすすめ）

[Overview](THunt-Framework/Core/Overview.md)
[WorkFlow](THunt-Framework/Core/WorkFlow.md)
[Constitution](THunt-Framework/Core/Constitution.md)


参照リンクにする（READMEがスッキリ）

[Overview][ov]
[WorkFlow][wf]
[Constitution][cs]

[ov]: THunt-Framework/Core/Overview.md
[wf]: THunt-Framework/Core/WorkFlow.md
[cs]: THunt-Framework/Core/Constitution.md


リンク先だけにする（自動リンク）

THunt-Framework/Core/Overview.md


※これはエディタやGitHubが自動でリンク化する前提。

「二重化してる理由」は仕様で、表示テキストとリンク先を同じに書いたのが原因だな。
