# 設定ダイアログ
メニューの「ボード→設定」の順番で
盤面の設定を変更するダイアログを生成してください。
出現中にゲーム画面は操作出来ません。

# 設定項目

## 盤面のボタンの縦の数

## 盤面のボタンの横の数

## 爆弾の数
盤面のマス目を超える数は、自動的に丸めます。

# 表示エリア
設定内容を表示します。

## 盤面の設定状況の表示
フォーマットは「縦 x 横 (爆弾の数)」で表示します。

## 盤面の爆弾の密度の表示
盤面のマス目の数のうちの、爆弾の密度を%表示します。

# お宝の数
「お宝」の数は現在は設定「しません」。
これは爆弾の数により自動的に設定されます。

## お宝の数
お宝の数 = 0～（爆弾の数 / 2）の範囲
（稀にお宝が存在しない可能性もあります）
爆弾の数が極端に多い場合、
お宝の最大数は保証されなくなります。

# OKボタン
OKボタンを押すことで設定が保存されます。
設定ファイルを盤面設定用のjsonに保存します。

# Cancelボタン
設定の変更があった場合は
設定破棄の確認をしてから、ダイアログを閉じます。
